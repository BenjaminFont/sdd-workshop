03 · c

Generieren vs. Binden

Generieren

Szenario erzeugt Testdatei → zwei Artefakte → driftet.

Binden

Szenario ist der Test → ein Artefakt → kein Drift.

Nur Binden schließt die Schleife.

03 · c

Zwei Schichten

  • *.feature — Prosa, lesbar. Die Spec.
  • steps/* — Code, einmal geschrieben, wiederverwendbar.

Der Runner verbindet beide zur Laufzeit. Die Leserlichkeit leidet nicht.

03 · c

Die Übersetzungsschicht

Given("a logged-in user", function () {
  this.system.login();
});
When("{int} minutes pass without activity", function (m) {
  this.system.advanceMinutes(m);   // {int} = aus dem Szenario
});
Then("the session is invalid", function () {
  assert.strictEqual(this.system.sessionIsValid(), false);
});

Die Zahl steht NIE im Code — sie kommt zur Laufzeit aus der .feature.

03 · c

Wann rot, wann grün?

  • ROT  15 min → still valid (Code sagt invalid)
  • ROT  20 min → still valid (über die Grenze)
  • GRÜN  30 min → invalid (gleiche Seite)
  • GRÜN  nur Titel / Kommentar geändert

03 · c

strict ist konstituierend

  • strict: true in cucumber.json — nicht im Step-File.
  • Szenario ohne Step-Definition → ROT.
  • Ohne strict: rutscht still als GRÜN durch → Drift kehrt zurück.

Nicht auf den Default verlassen — explizit setzen.
