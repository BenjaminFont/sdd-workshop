Kontext kuratieren — 4 Strategien

  • Write — Wichtiges festhalten (Dateien, Memory)
  • Select — nur Relevantes hereinholen
  • Compress — verdichten, zusammenfassen
  • Delegate — an Subagents auslagern
00

Context Files — die Kategorien

  • Plans — was als Nächstes
  • AGENT.md / CLAUDE.md — Dauerwissen
  • Docs — Nachschlagewissen
  • Rules — Verhaltensregeln

CLAUDE.md

Rules & Progressive Disclosure

  • Conditional Rules — gelten nur für bestimmte Pfade (applyTo / paths:)
  • Progressive Disclosure — SKILL.md verweist auf Details, die nur bei Bedarf geladen werden

Beides hält die Smart Zone schlank.
