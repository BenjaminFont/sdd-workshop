Die Domänen-Form

Domäne (Datei)→ Requirement→ Scenario

OpenSpec-Form: nach Domäne sortiert, nicht pro Feature.

03 · b

Eine grüne Karte → ein Szenario

Feature: Skill-Import

  Scenario: Ziel existiert bereits in älterer Version
    Given ein Repo mit Skill "lint" in Version 1.2.0
    When ich Skill "lint" Version 1.4.0 importiere
    Then wird die Datei überschrieben

Lesbar für jeden — das ist die Spezifikation selbst.

03 · b

Eine Anforderung gehört in

Given / When / Then

niemals in den Freitext.

03 · b

Warum diese Disziplin?

  • Freitext unter Feature: wird still ignoriert.
  • Eine Anforderung dort steht da — wird aber nie geprüft.
  • Nur Given/When/Then wird später zum Test.
